# City textures

Generated with the built-in OpenAI image generation tool on 2026-09-24 for Ion Rush.
Exact final prompts are in [generation-prompts.json](generation-prompts.json).

- `office-facade.png`: dark glass and varied warm/neutral office interiors. World-space tiled, mipmapped facade material; procedural per-building scale, offset and lighting variation.
- `city-billboards.png`: four-panel atlas with portrait, vehicle, botanical and energy advertising art. Text is rendered in-game for clean lettering.

Original generated PNGs are copied unmodified. No online services are required to play.

## Corporate advertisements

`corporate-posters.png` is the runtime 3x2 atlas of six AI-generated 1:2
portrait campaigns: SABLE cybernetics, SOMA neurochemistry, TALLY instant credit,
VEIL subscription privacy, MONOLITH infrastructure and APERTURE optical implants.
Created using the built-in OpenAI image generation tool on 2026-09-28.
Unmodified generated sources and the exact prompt set are in
[`docs/city-advertising`](../docs/city-advertising/generation-prompts.json).
`tools/pack_city_ads.gd` only resizes and packs the originals into the mipmapped
1536x2048 atlas. No external services are used during play. Posters and road
reflections sample the same full-color artwork with a subtle screen refresh.

## Superseded neon storefront experiment

`neon-signs.png` contains 16 original designs authored by
`tools/generate_neon_signs.py`: RAMEN, PULSE, ORBIT, VOLT, LOTUS, NOVA,
BYTE, AERO, MISO, LUNA, HELIX, KINETIC, O2, HORIZON, VECTOR and METRO.
The artwork uses an original stroke alphabet and geometric icons, with no
external fonts or downloaded images. RGB channels pack the primary tubes,
secondary tubes and animated accents into one mipmapped 2048px atlas.
`neon-signs-preview.png` is the design contact sheet, not a runtime texture.
This earlier graphic direction is no longer referenced by the game.

# Vehicle wear

`paint-wear.png` is an original deterministic procedural mask generated by
`tools/generate_paint_wear.py` (seed 90419), not an AI image or downloaded asset.
R stores a chip threshold field, G scratches, B broad dirt/smoke variation.
It is a 512px RGB data texture with mipmaps, shared by all cars.

Research reference: Rasmus_02's CC0 [Wear and Tear Shader](https://godotshaders.com/shader/color-replacer-pixel-perfect-damage-shader/)
uses noise thresholds to expose a material beneath paint. Our 3D implementation
uses that general technique with original masks, triplanar projection, roughness,
metalness and clearcoat response; no source code or media were copied.
Shader API: [Godot 4.5 spatial shaders](https://docs.godotengine.org/en/4.5/tutorials/shaders/shader_reference/spatial_shader.html).
