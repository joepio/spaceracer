Windows x64 portable build of **Ion Rush**, developed in `joepio/spaceracer`.

- Download `ion-rush-windows.zip`, extract it, and run `IonRush.exe`. No Godot installation is needed.
- Supports 1–4 local players with controllers, AI opponents, and the GameNight protocol.
- Three procedural settings: neon city, forest, and the cell. Includes flight, boost, weapons and energy recharge strips.
- This is an unsigned development build. Audio is currently disabled. Vulkan-capable graphics are required; use Balanced or Performance for lower-end hardware or split-screen.

`release-sha256.txt` verifies the ZIP. `ion-rush.catalog.json` contains its versioned URL, checksum, entrypoint and artwork for GameNight's catalog. This release has automated simulation and packaged protocol checks; it does not claim full hardware certification.
